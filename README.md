# 闪电 隐私政策

最后更新：2026-10-23

本隐私政策适用于「闪电」应用（包名 `com.heaven.shandian`，以下简称"本应用"）。我们非常重视你的隐私，本应用的设计原则是**不收集、不上传你的任何个人数据**。

## 一、我们不收集的信息

本应用**不收集**以下信息，也不将其上传到任何服务器：

- 你的姓名、手机号、邮箱、账号等身份信息（本应用没有账号体系）；
- 你的通讯录、短信、照片、麦克风、摄像头、位置等系统隐私数据；
- 你的上网记录、访问的域名与 IP、DNS 查询内容。

## 二、仅在本机保存的数据

以下数据**只保存在你设备的应用沙盒内**（卸载应用即删除），不会上传：

- 你导入的节点信息、订阅地址、分组与选中状态；
- 你自定义的分流规则与规则集文件；
- 应用的设置项（DNS、MTU、日志级别等）；
- 运行日志（仅本机，可在应用内一键清空）。

## 三、仅在你主动操作时发起的网络请求

本应用只会在你主动触发下列功能时访问网络，且请求目标由你指定：

| 场景 | 请求目标 | 用途 |
|---|---|---|
| 导入/更新订阅 | 你填写的订阅地址 | 拉取节点列表 |
| 导入规则集 / 一键国内直连 | 你填写的地址，或官方规则集镜像（jsDelivr / GitHub） | 下载分流规则文件 |
| 延迟测试 | 你在设置中填写的测速地址（默认 `https://www.gstatic.com/generate_204`） | 测量节点延迟 |
| 代理连接 | 你配置的代理服务器 | 转发你自身产生的网络流量 |

上述请求不含任何用户标识信息，我们（应用开发者）不运营任何用于收集数据的服务器。

## 四、系统权限说明

- **网络访问（INTERNET）**：建立代理连接、下载订阅与规则集；
- **获取网络信息（GET_NETWORK_INFO）**：读取当前默认网卡名称，用于绑定物理网卡以避免流量回环；
- **VPN 服务（系统 VPN 扩展）**：在你主动点击"连接"后创建本地 TUN 通道，把流量转发到你配置的代理服务器。该通道的流量不会被本应用记录或上传；
- **通知**：在通知栏显示连接状态与实时速率；
- **文件选择**：仅访问你在系统文件选择器中主动选中的单个文件（导入规则集、导入/导出配置备份）。

你可以随时在系统设置中关闭通知、断开 VPN，或卸载本应用。

## 五、第三方

本应用不集成任何广告、统计、推送或社交 SDK，也不会向任何第三方出售、共享你的数据。

## 六、儿童隐私

本应用不面向 13 岁以下儿童，也不会有意收集儿童信息。

## 七、数据安全

本应用的全部配置与日志均保存在应用沙盒内，受操作系统沙盒保护。请注意：**代理服务器由你自行提供**，其数据处理行为由该服务提供者负责，与本应用开发者无关。

## 八、政策更新

本政策如有更新，会在应用新版本发布时同步更新本页面，并更新"最后更新"日期。
